Recomendado: Cloudflare Worker + AI
📘 Cómo crear y conectar el Cloudflare Worker paso a paso
  1. Entra en Cloudflare Dashboard y abre Workers & Pages.
  2. Pulsa Create → Worker (o Create application → Worker, según la interfaz) y ponle un nombre. Si ya tienes un Worker que funciona, puedes actualizarlo en vez de crear otro.
  3. Abre Edit code, selecciona el código de ejemplo y sustitúyelo por el código de esta web usando 📋 Copiar Código del Worker v4 (.JS). Pulsa Deploy.
  4. En la configuración del Worker, abre Settings → Bindings (o Compute → Workers AI) y añade un binding de tipo Workers AI llamado exactamente AI. Guarda los cambios y vuelve a desplegar si te lo pide.
  5. En Settings → Variables and Secrets, añade un secreto llamado exactamente APP_SECRET. Usa una contraseña larga y aleatoria. Debe ser la misma que pongas en el campo de abajo; no la compartas ni la publiques.
  6. Copia la URL pública del Worker que termina en .workers.dev y pégala en URL del Worker. Pega la misma clave en APP_SECRET y pulsa Comprobar Worker Cloudflare.
  7. Si la prueba funciona, selecciona Cloudflare Worker (FLUX.1) como motor de imagen. La IA de texto también usa el Worker. Las voces Cloudflare usan su propia cuota; para Azure Neural configura AZURE_SPEECH_KEY como secreto y AZURE_SPEECH_REGION como variable, dentro del Worker, nunca en esta página.

Importante: cambiar de nombre o URL al Worker no aumenta la cuota de la cuenta Cloudflare. No publiques el secreto APP_SECRET dentro del código HTML o en repositorios públicos.
