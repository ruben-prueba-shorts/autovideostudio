CONFIGURACIÓN ÚNICA, SIN INSTALAR PROGRAMAS

Conecta tu cupo gratuito

Si tu URL actual ya genera imágenes, puedes conservarla para eso. Para guion y voz necesitas el servidor de esta versión. Créalo en un Worker nuevo para conservar tu configuración anterior.

  1. Abre Cloudflare y crea una cuenta o entra en la tuya. Elige Free. No añadas una suscripción de pago ni créditos de AI Gateway.
  2. Entra en Workers & Pages (puede aparecer dentro de Compute & AI). Pulsa Create application → Create Worker o Start with Hello World.
  3. Pon un nombre nuevo, por ejemplo mi-estudio-gratis, y pulsa Deploy.
  4. En el Worker pulsa Edit code. Borra el ejemplo, pega el código del botón de arriba y pulsa Deploy.
  5. Vuelve a tu Worker. Entra en Bindings → Add binding → Workers AI. Escribe AI como nombre y guarda.
  6. Entra en Settings → Variables and Secrets → Add. Elige tipo Secret, nombre APP_SECRET y escribe una clave larga que inventes (por ejemplo, cuatro palabras y números). Guarda y despliega si aparece el botón.
  7. Copia la dirección https://tu-worker.tu-cuenta.workers.dev del Worker. Pégala en URL del Worker de esta página y pega tu misma clave en APP_SECRET.
  8. Pulsa Comprobar Cloudflare. Debe indicar imágenes, texto y voz. Si solo indica imágenes, tu servidor es de una versión anterior.
  9. En Plan gratuito comprueba el cálculo. Empieza por un guion corto y pulsa Probar voz. No necesitas tarjetas ni una API key de Cloudflare en este HTML; solo la clave APP_SECRET que elegiste.
Si algo falla

401: revisa APP_SECRET. 503 que menciona AI: añade el binding AI. 429/cupo diario: conserva el proyecto y espera al siguiente reinicio. 413: divide el prompt (máximo 2.048 caracteres). Algunos modelos pueden no estar disponibles para tu cuenta: la aplicación mostrará el error y conservará los fragmentos terminados. No sustituye modelos por otros de pago.

En Cloudflare, Workers AI → Usage muestra el consumo real. El contador del HTML es solo una previsión. La configuración del panel puede cambiar de nombre con futuras actualizaciones.

Cómo crear tu primer vídeo
  1. En Plantilla elige estilo, personaje y formato.
  2. En Guion pega una escena por línea o genera un borrador. Revisa su contenido y aplica ritmo si deseas otra cantidad de imágenes.
  3. En Audio sube tu narración o prueba y genera una voz. Mantén el mismo texto del guion.
  4. Pulsa Generar imágenes. Los prompts se pueden revisar y editar antes. No cierres la pestaña mientras trabaja.
  5. Pulsa Sincronizar todo. El modelo de reconocimiento se descarga la primera vez. Revisa la vista previa y las escenas antes de exportar.
  6. Elige resolución (720p, 1080p o 1440p), 30 o 60 fps y pulsa Descargar MP4. En modo rápido puedes cambiar de pestaña; no la cierres hasta que termine.
  7. En Clips añade rangos o divide cada 60 segundos. Ajusta texto y encuadre. Descarga cada clip por separado.
  8. Pulsa Guardar proyecto para guardar guion, imágenes, sonido y clips en un archivo que puedes volver a abrir. Las plantillas se guardan también en este navegador.
